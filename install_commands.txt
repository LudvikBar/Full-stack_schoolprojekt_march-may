To generate an Electron Forge app

- npm create electron-app@latest my-app

Move into the app
- cd my-app

To start the app
- npm start




Install Supabase - make sure o install it in the same folder as electron. so on the same folder lvl as node_modules, packadge.json and more
- npm install @supabase/supabase-js


Take pub key and url, make .env and but them there.

# lets node read .env
- npm install dotenv

Add to index.js or main.js in electron app src
- require('dotenv').config()

preload "run" supabase client with your url and key aka your project.

-const { createClient } = require('@supabase/supabase-js')
- const supabase = createClient(
-   process.env.SUPABASE_URL,
-   process.env.SUPABASE_ANON_KEY
- )
- module.exports = supabase
